# Contributing

Thanks for considering a contribution! This project is open to improvements of all kinds.

## What We're Looking For

- **Resume advice improvements** -- corrections, additions, or updates to the guide
- **Before/after examples** -- anonymized real-world bullet rewrites
- **Role-specific keyword lists** -- new roles or updated keywords for 2025/2026
- **Claude Code skill improvements** -- better analysis, new checks, bug fixes
- **Translations** -- making the guide accessible in more languages

## How to Contribute

1. **Fork** the repo
2. **Create a branch** for your change (`git checkout -b add-design-role-keywords`)
3. **Make your changes** -- one focused change per PR
4. **Submit a PR** with a clear description of what you changed and why

## Guidelines

- Keep advice actionable and specific -- no vague platitudes
- Include sources when possible (link to articles, studies, or books)
- Before/after examples should be anonymized (no real names or companies)
- Test the Claude Code skill if you modify it

## Code of Conduct

Be respectful. We're all here to help people get hired.

## Questions?

Open an issue or start a discussion. No question is too basic.
