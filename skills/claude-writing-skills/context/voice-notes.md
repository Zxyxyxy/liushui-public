# Voice Notes

Your personal style bank. The `/draft` and `/top-edit` skills read this file before writing or screening prose to calibrate against your actual voice.

This file is empty when you start. It grows as you publish. After each top-edit pass, the skill recommends 1-2 paragraphs to add — the ones that most characteristically sound like you. Over time this becomes the most important file in the system.

---

## How to Use This File

- After publishing a piece, run `/top-edit` and approve the recommended paragraphs to add here
- Group entries by section: **Openings**, **Analytical Paragraphs**, **Closings**
- Each entry should include the paragraph (block-quoted), a one-line label, and a short annotation explaining what move the paragraph makes
